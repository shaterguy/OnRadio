온라디오 0.1.0-dev1

국내 FM 12개 채널을 청취하는 Android 앱입니다.

- 방송 목록, 방송명·주파수 검색, 즐겨찾기 저장.
- 목록 스크롤과 독립된 하단 미니 재생바, 재생/일시정지, 이전/다음 채널.
- 미니바를 누르면 별도 재생화면으로 이동.
- 방송사, 주파수, 현재 프로그램명·방송시간·프로그램 설명 표시.
- KBS·MBC·SBS·CBS 앱 내 당일 편성표. EBS 공식 편성표 링크.
- Media3 백그라운드 재생, 미디어 알림과 잠금화면 컨트롤.

Android 8.0 이상. FM 전파 수신 방식이 아닌 인터넷 스트리밍 방식으로 데이터 통신이 필요합니다.

빌드·정적 검사·단위 테스트, 12개 채널 음성 세그먼트 수신, 11개 채널 공식 편성 API 검증을 수행했습니다. ADB 연결 기기가 없어 실제 화면·설치·장시간 청취 시험은 미검증입니다.
