온라디오 0.1.0-dev9

- 편성표 시작·종료 시각과 현재 시각으로 프로그램 진행률을 계산해 하단 고정 재생바와 재생화면에 표시합니다. 재생 시작 시점이나 버퍼 위치를 진행률로 사용하지 않습니다.
- 일시정지 중에도 방송 시각을 기준으로 갱신하며 프로그램이 바뀌면 새 편성을 반영합니다. 편성정보가 없으면 진행률을 숨깁니다.
- 알림·잠금화면에는 동일한 프로그램 길이와 경과시간을 전달합니다. 시스템별 표시 모양은 Android가 결정합니다.
- 모든 시간 탐색 명령과 드래그 이동을 차단합니다. 이전/다음 채널 이동과 명시적 재생 시 라이브 복귀는 유지합니다.
