온라디오 0.1.0-dev3

- 오늘의 편성표를 열면 현재 방송 중인 항목이 스크롤 영역 가운데에 표시됩니다. 상단·하단 항목도 가운데로 이동할 수 있도록 여백을 확보했습니다.
- 별도 정렬 선택 메뉴를 제거하고 목록 상단에 주파수·방송국명 열 제목을 배치했습니다.
- 열 제목을 누르면 해당 기준으로 정렬하며, 같은 제목을 다시 누르면 오름차순과 내림차순이 바뀝니다. 다른 기준을 선택하면 오름차순으로 시작합니다.
- 현재 정렬 중인 열에만 검정색 ▲ 또는 ▼를 표시합니다. 열 제목도 검정색입니다.
- 정렬 기준과 방향은 앱 종료 후에도 유지됩니다. 기존 주파수순·방송국 이름순 설정을 이어갑니다.

기존 14채널·즐겨찾기·현재 프로그램명·하단 고정 재생바를 유지합니다. kr.jinsu.radio.dev 및 기존 개발 서명을 유지하고 versionCode를 3으로 증가시켰습니다.

실기기 화면 렌더링은 미검증이며 소스 검토·빌드·정적 검사·동작 규칙 단위 테스트와 구분합니다.

블루투스 이어폰 해제 시 재생 중지: Media3 오디오 출력 전환 처리와 Bluetooth A2DP·SCO·LE Audio·보청기 출력 제거 콜백을 함께 적용한다. 마지막 Bluetooth 출력이 제거되면 재생과 스트리밍을 중지하고, 연결 해제 전 시작된 방송 주소 조회가 나중에 완료돼도 스피커로 자동 재생하지 않는다. 재연결만으로 자동 재생하지 않으며 Bluetooth 연결 권한을 새로 요구하지 않는다. 실제 이어폰 연결·해제는 실기기 미검증 항목이다.

재생바 터치 시 재생화면의 상단과 본문을 180ms 동안 48dp 아래에서 위로 부드럽게 전환한다. 하단 재생바는 움직이지 않고, 시스템 애니메이션 비활성 설정을 존중한다. 화면 이동으로 분리된 View의 중앙이동 콜백은 즉시 해제한다. 재생 요청에는 오디오 출력 세대값을 실어 서비스의 실제 play/setPlayWhenReady 시점에도 연결 해제 이전 요청을 거부한다.
