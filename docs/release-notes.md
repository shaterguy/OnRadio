온라디오 0.1.0-dev5

- 48dp 부분 이동을 화면 높이 전체 이동으로 교체했습니다. 재생화면이 아래에서 올라오고 뒤로가기하면 화면 아래 끝까지 내려갑니다.
- 열기/닫기 시간을 600ms로 늘리고 처음과 끝이 부드러운 동일 속도 곡선을 적용했습니다. 투명도 효과를 제거했습니다.
- 전환 중 방송 목록이 배경으로 보이며 하단 재생바는 움직이지 않습니다.
- 상단/시스템 뒤로가기, 중복 입력 차단, 화면 재구성 취소, 시스템 애니메이션 비활성 설정을 처리합니다.

기존 14채널·즐겨찾기·정렬·편성표·블루투스 해제 중지를 유지합니다. 실제 단말 애니메이션 체감은 미검증입니다.
