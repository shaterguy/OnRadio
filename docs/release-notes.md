온라디오 0.1.0-dev2

- TBS FM 95.1과 YTN 라디오 94.5만 추가하여 총 14개 채널을 제공합니다.
- 하단 재생바의 화면 부착 누락을 수정했습니다. 목록·즐겨찾기·편성표·재생화면에서 현재 방송정보와 이전/재생·일시정지/다음 컨트롤이 하단에 고정됩니다.
- 재생바를 누르면 별도 재생화면으로 이동합니다. 중앙의 중복 컨트롤을 제거했습니다.
- 방송 목록에 현재 프로그램명과 방송시간을 표시하며, 방송이 바뀌면 스크롤 위치를 유지하고 내용을 갱신합니다. EBS·TBS·YTN의 공식 편성정보 조회도 추가했습니다.
- 기본 정렬은 주파수 오름차순입니다. 방송국 이름순을 선택할 수 있고 선택은 앱 종료 후에도 유지됩니다. 이전/다음 방송도 같은 정렬 순서를 따릅니다.

기존 kr.jinsu.radio.dev 패키지와 개발 서명을 유지하고 versionCode를 2로 증가시킵니다. 기존 앱 위에 업데이트하여 즐겨찾기를 보존합니다.

실기기 화면 렌더링·설치·장시간 청취는 미검증이며 소스 검토·빌드·정적 검사·단위 테스트·공식 편성 API 및 음성 세그먼트 수신 검증과 구분합니다.
