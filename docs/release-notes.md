온라디오 0.1.0-dev8

- 알림창·잠금화면·미디어 버튼의 이전/다음 명령을 서비스의 주파수 순 채널 변경에 연결했습니다. 단일 스트림에서도 이전/다음 명령을 활성화합니다.
- 앱 내부 하단 버튼도 동일한 미디어 세션 경로를 사용합니다. Activity 없이 서비스에서 스트림 주소를 조회하고 재생합니다.
- 즐겨찾기 탐색 범위, 연속 입력 누적, 양끝 순환을 유지합니다.
- 정지/일시정지/블루투스 해제/다른 방송 선택 시 이전 채널 조회 완료가 재생을 덮지 않도록 요청을 무효화합니다.

실기기의 알림·잠금화면 렌더링은 자동 검증과 별도로 구분합니다.
