# 온라디오 0.1.0-dev2

국내 FM 방송 인터넷 청취 앱. 네이티브 Android UI와 Media3 세션 서비스로 구현한다. 별도 계정·자체 중계서버·유료 API는 사용하지 않는다.

- AC1: FM 채널 목록과 검색, 즐겨찾기 저장/해제 및 재실행 후 복원.
- AC2: 스크롤 영역 밖에 고정된 미니 재생바와 재생/일시정지, 이전/다음 채널.
- AC3: 미니바 탭 시 별도 재생화면. 뒤로 돌아가도 재생 유지.
- AC4: 재생화면에 방송사, 채널명, 수도권 기준 FM 주파수, 현재 프로그램과 시간, 채널 설명.
- AC5: 제공되는 공식 편성 데이터는 앱 내 당일 편성표로 표시. 제공되지 않거나 조회 실패 시 상태와 공식 편성표 링크 표시. 프로그램명 추정 금지.
- AC6: 화면 꺼짐/백그라운드 미디어 세션, 알림/잠금화면 컨트롤, 오디오 포커스·이어폰 분리 처리.
- AC7: 연결 중/일시정지/오류 상태와 재시도. 채널 전환의 오래된 비동기 응답이 현재 채널을 덮어쓰지 않아야 한다.

디자인: 조용하고 따뜻한 수신기. 밝은 중성 배경과 구리색 강조, 방송 주파수 숫자와 정적 튜닝 눈금이 식별 요소다. 시스템 글꼴, 최소 48dp 터치 영역, 시스템 바 인셋과 큰 글꼴을 지원한다. 과도한 장식·움직임은 사용하지 않는다.

개발용 패키지 kr.jinsu.radio.dev, versionCode 2. 소스와 빌드 산출물의 SHA-256을 검증한다. 실제 기기 자동검증 가능 여부를 별도로 기록한다.

추가 요구사항: 신규 채널은 TBS FM·YTN만 추가한다(총 14개). 모든 화면에서 하단바를 실제 root에 부착하며 스크롤 영역 밖에 둔다. 방송 목록의 프로그램명·시간은 동적으로 갱신한다. 주파수순이 기본이고 방송국 이름순 선택과 재실행 후 정렬기준 복원을 지원한다.
