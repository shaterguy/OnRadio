# 온라디오 0.1.0-dev3

국내 FM 방송 인터넷 청취 앱. 네이티브 Android UI와 Media3 세션 서비스로 구현한다. 별도 계정·자체 중계서버·유료 API는 사용하지 않는다.

- AC1: FM 채널 목록과 검색, 즐겨찾기 저장/해제 및 재실행 후 복원.
- AC2: 스크롤 영역 밖에 고정된 미니 재생바와 재생/일시정지, 이전/다음 채널.
- AC3: 미니바 탭 시 별도 재생화면. 뒤로 돌아가도 재생 유지.
- AC4: 재생화면에 방송사, 채널명, 수도권 기준 FM 주파수, 현재 프로그램과 시간, 채널 설명.
- AC5: 제공되는 공식 편성 데이터는 앱 내 당일 편성표로 표시. 제공되지 않거나 조회 실패 시 상태와 공식 편성표 링크 표시. 프로그램명 추정 금지.
- AC6: 화면 꺼짐/백그라운드 미디어 세션, 알림/잠금화면 컨트롤, 오디오 포커스·이어폰 분리 처리.
- AC7: 연결 중/일시정지/오류 상태와 재시도. 채널 전환의 오래된 비동기 응답이 현재 채널을 덮어쓰지 않아야 한다.

디자인: 조용하고 따뜻한 수신기. 밝은 중성 배경과 구리색 강조, 방송 주파수 숫자와 정적 튜닝 눈금이 식별 요소다. 시스템 글꼴, 최소 48dp 터치 영역, 시스템 바 인셋과 큰 글꼴을 지원한다. 과도한 장식·움직임은 사용하지 않는다.

개발용 패키지 kr.jinsu.radio.dev, versionCode 3. 소스와 빌드 산출물의 SHA-256을 검증한다. 실제 기기 자동검증 가능 여부를 별도로 기록한다.

추가 요구사항: 신규 채널은 TBS FM·YTN만 추가한다(총 14개). 모든 화면에서 하단바를 실제 root에 부착하며 스크롤 영역 밖에 둔다. 방송 목록의 프로그램명·시간은 동적으로 갱신한다. 주파수순이 기본이고 방송국 이름순 선택과 재실행 후 정렬기준 복원을 지원한다.

DEV3: 편성표 진입 시 현재 방송 행 중앙 이동. 주파수/방송국명 열 제목 터치 정렬 및 같은 열 재터치 방향 전환. 현재 정렬 열에만 검정 ▲/▼ 표시. 기준·방향 재실행 복원. 별도 정렬 메뉴 제거.

블루투스 이어폰 해제 시 재생 중지: Media3 오디오 출력 전환 처리와 Bluetooth A2DP·SCO·LE Audio·보청기 출력 제거 콜백을 함께 적용한다. 마지막 Bluetooth 출력이 제거되면 재생과 스트리밍을 중지하고, 연결 해제 전 시작된 방송 주소 조회가 나중에 완료돼도 스피커로 자동 재생하지 않는다. 재연결만으로 자동 재생하지 않으며 Bluetooth 연결 권한을 새로 요구하지 않는다. 실제 이어폰 연결·해제는 실기기 미검증 항목이다.

재생바 터치 시 재생화면 전체를 420ms 동안 아래에서 위로 전환하고 뒤로가기하면 아래 끝까지 내려간다. 하단 재생바는 움직이지 않고, 시스템 애니메이션 비활성 설정을 존중한다. 화면 이동으로 분리된 View의 중앙이동 콜백은 즉시 해제한다. 재생 요청에는 오디오 출력 세대값을 실어 서비스의 실제 play/setPlayWhenReady 시점에도 연결 해제 이전 요청을 거부한다.

하단 재생바 이전/다음은 목록 정렬과 무관하게 주파수 오름차순으로 채널을 이동한다. 즐겨찾기 화면에서는 즐겨찾기 범위, 비어 있으면 전체 채널을 사용하며 양 끝에서는 순환한다.
